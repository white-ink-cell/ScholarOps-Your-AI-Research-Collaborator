# Synthetic input

A proposed credit-market study needs transaction-level timestamps and dealer identifiers from a licensed institutional bond dataset for 2012–2025.

The user can log into the vendor platform, but has not verified:

- whether the specific transaction table is included in the subscription;
- whether 2012–2015 history is available;
- whether bulk export is permitted.

A public website provides daily issuer-level average bond yields but no transaction timestamps or dealer identifiers.

Task: Decide whether the study has research-grade access and whether the public website is an equivalent fallback.
