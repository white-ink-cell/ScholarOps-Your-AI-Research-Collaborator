# Expected decision

The 8-minute rule may be frozen as a **resource-allocation progression criterion** for this screen if it is defensible for the funding decision.

If the screen misses the criterion, the allowed verdict is `STOP_RESOURCE_ALLOCATION`, not “the effect is economically zero” or “no meaningful productivity effect exists.”

A formal SESOI/equivalence/economic-null conclusion requires `FORMAL_STUDY` and Freeze B. This fixture exercises the screen-versus-formal-study boundary.
