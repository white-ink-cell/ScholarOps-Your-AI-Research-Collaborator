# ScholarOps

Read `00_CANONICAL_INDEX_EN.md` first. Then use `runtime/TASK_ROUTER.csv` and `runtime/GATE_ACTIVATION_POLICY.csv` to load only the modules required by the current research task.

- `RE` recovers project state and stops when invoked alone.
- `AU` audits the current research workflow and stops when invoked alone.
- No execute command is required; once ScholarOps is loaded, route substantive research tasks automatically.

Load the optional AI × Finance profile only when the research task explicitly requires it.
